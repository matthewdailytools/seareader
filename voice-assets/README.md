# SeaReader Japanese offline voice assets v1

The bundled files are unchanged upstream artifacts. SeaReader verifies their SHA-256 hashes before installing the voice.

- `engine.tgz` contains the Open JTalk WebAssembly CLI and its upstream license notices. [npm package](https://www.npmjs.com/package/wasm_open_jtalk/v/0.0.1)
- The dictionary uses the NAIST Japanese Dictionary. Its Debian package includes the original copyright and licensing information. [Debian source package](https://tracker.debian.org/pkg/open-jtalk)
- `mei_normal.htsvoice` is HTS Voice Mei by the MMDAgent Project Team at Nagoya Institute of Technology. The accompanying `voice-license.txt` includes the CC BY 3.0 attribution and license terms. [Upstream voice and license](https://github.com/r9y9/pyopenjtalk/tree/0f0fc44e782a8134cd9a51d80b57b48a7c95bb80/pyopenjtalk/htsvoice)
